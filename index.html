Simulador de transmisión de epidemias

Un modelo SIR sencillo hecho con JavaScript y Canvas: las personas se mueven, se contagian y se recuperan. Guía Práctica Semana 04, IS093A.

1 Estructura HTML, interfaz y canvas

En el modelo SIR cada persona está en un estado: susceptible (S), infectada (I) o recuperada (R). Una persona infectada contagia a las susceptibles que se le acercan y, pasados unos segundos, se recupera. La interfaz usa solo HTML, CSS y un <canvas>; el script se carga con defer. Escribe el nombre del brote (por ejemplo, el virus) y aparece en letras de neón.

2 IIFE, closures y arrow functions

Todo el código vive dentro de una IIFE, así que no crea variables globales. El estado de la simulación está guardado en un closure: sigue disponible entre un frame y otro sin salir del scope. Los handlers son arrow functions, que conservan el this léxico. Con el botón puedes introducir un caso: infecta a una persona susceptible y el closure suma uno al contador.

3 Manipulación del DOM y validación

Esta caja representa a una persona. Con classList.toggle() y variables CSS cambia de estado sin usar style inline: al contagiarla se pone roja y emite un pulso que representa su radio de contagio; al recuperarla se pone verde; en cuarentena se detiene. 4 Canvas API y requestAnimationFrame

La simulación avanza con requestAnimationFrame y delta time, por lo que las personas se mueven igual en pantallas de 60 o 144 Hz. Abajo se dibuja la curva epidémica con stroke: la línea roja sube cuando hay más infectados.
